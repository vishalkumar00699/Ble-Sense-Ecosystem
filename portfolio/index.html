BLE Sense Web Dashboard
A React + Vite web dashboard that visualizes high-frequency BLE accelerometer data streamed from the Android app through a Node.js/Express backend. Displays 80-point sensor packets as interactive charts with signed m/s² scaling.
  • Real-time accelerometer charts with Recharts
  • 80-point packet visualization per sensor burst
  • Signed int8 → m/s² conversion (÷6.4 firmware scale)
  • Interactive packet detail modal view
  • REST API polling from Node.js + MongoDB backend
  • Network-accessible via LAN or Ngrok tunnel
  • Live upload indicator synced with Android app
React Vite Recharts Axios Node.js Express MongoDB
